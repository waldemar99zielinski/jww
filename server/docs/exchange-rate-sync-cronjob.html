Backend Design Analysis

Daily exchange-rate sync via a cron job

A scheduled job inside cmd/server that pulls current rates from the Frankfurter API once a day and records them as currency_exchange_rates rows — designed to fit the existing Clean Architecture, hexagonal ports, unit-of-work and testing conventions of the jww server.

Target: server/ Provider: Frankfurter v2 (no API key) Recommended scheduler: robfig/cron v3 2026-10-15

01 Recommendation (TL;DR)

Use github.com/robfig/cron/v3 and a new outbound port RateSource. Wrap the cron library in one infrastructure package (internal/infrastructure/scheduler), implement the port in a new adapter (internal/adapter/frankfurter), and put the orchestration in a new method on the existing workflow (CurrencyExchangeRateWorkflow.SyncDaily). Persist through the existing repository/gateway with an idempotent INSERT … ON CONFLICT DO NOTHING — no schema migration is required.
  • Library: robfig/cron/v3 — the de-facto Go cron library, zero transitive dependencies, standard cron syntax, per-schedule timezone, built-in panic recovery & overlapping-run guards, and a Stop() that returns a context so it slots straight into the server's existing SIGTERM shutdown.
  • Direction: store from = foreign currency, to = base currency (PLN) — the exact direction SummaryWorkflow.convert already looks up.
  • Idempotency: anchor each row's recorded_at to the rate's own business date at 00:00 UTC. Re-running, restarting, or catching up the same day then becomes a no-op through the table's existing primary key.
  • Layering: the cron library is confined to the outermost layer; the workflow depends on the RateSource port, never on the Frankfurter adapter.
  • Loop of control: HTTP fetch happens before the DB transaction opens (no tx held during network I/O); all writes land in one unit of work.

  • Exactly the features needed, nothing more.
  • Deployed everywhere (5.5k+ importers); its API is stable and well understood.
  • cron.Stop() returns a context.Context that closes when running jobs finish — a natural fit for main.go's 10s graceful shutdown.

Note on release cadence

robfig/cron v3.0.1 dates to 2020, but the package is feature-complete and its issue tracker is quiet rather than abandoned. If a policy requires an actively released dependency, netresearch/go-cron is a near drop-in fork with the same API. Either way, the wrapper below keeps the choice swappable in one file.

03 The Frankfurter API

Frankfurter is a free, open-source exchange-rate API aggregating 104 central banks and official sources. No API key, no quotas. Its FAQ explicitly encourages storing daily observations locally for caching — which is precisely what this job does.

Endpoints used

# One currency pair (base → quote). This is the call the adapter makes, once per held currency.
curl "https://api.frankfurter.dev/v2/rate/eur/pln"
// => {"date":"2026-10-15","base":"EUR","quote":"PLN","rate":4.3711}

# All quotes for one base (alternative / batching — see note below).
curl "https://api.frankfurter.dev/v2/rates?base=PLN&quotes=EUR,USD"
// => [{"date":"2026-10-15","base":"PLN","quote":"EUR","rate":4.3711}, ...]
PropertyValue / implication
Base URLhttps://api.frankfurter.dev (configurable, so it can be self-hosted or pointed at a test double)
AuthNone. Anonymous, no request logging — nothing secret to configure.
rateUnits of quote per 1 unit of base. Returned as a bare JSON number (e.g. 4.3711). Decode it as json.Number and hand the text to domain.ParseExchangeRate — never float64.
dateThe rate's business date (YYYY-MM-DD), not the fetch time. On weekends/holidays it is the last business day. This is what we anchor recorded_at to.
Errors404/422 = unknown or unsupported currency; 5xx = transient. JSON body {"status":…,"message":…}.
CadenceDaily; ECB-sourced rates publish around 16:00 CET. No intraday movement to chase.
Direction matters — and it is already decided for us. SummaryWorkflow.convert resolves GetByCurrencies(txn.Currency → target, …) and multiplies the amount. The stored rate must therefore be from = foreign, to = base (e.g. EUR→PLN = 4.3711). Frankfurter's /v2/rate/{from}/{to} returns exactly that shape, so we call it per held currency and store the pair verbatim — no float inversion, no precision loss.
Why per-pair calls instead of one ?base= call. /v2/rates?base=PLN only ever returns PLN→foreign, the opposite of what the summary needs. Producing the required foreign→PLN rows from that response would require inverting every rate in fixed point. The app holds a handful of currencies, so N−1 direct pair calls once a day is cheaper (in complexity) than inversion — and Frankfurter is edge-cached with no quota. The RateSource port leaves room to switch to a batched implementation later without touching the workflow.

06 Runtime flow diagram

  1. The cron tick fires; the scheduler wrapper builds a fresh domain.AppContext with source_type=scheduler, a new flow_id, and a per-run timeout, then calls the job.
  2. SyncDaily lists the app's currencies and finds the one flagged IsBase (PLN). If none is set, it fails fast — the known "at least one base" gap surfaces here rather than silently doing nothing.
  3. It calls rateSource.Latest(ctx, base, foreignCodes). The adapter issues one /v2/rate/{code}/{base} request per foreign currency and returns []Quote. Transport/decoding/5xx errors abort the run; a 404/422 (currency unsupported by the provider) simply omits that pair.
  4. Only now does the workflow open one unit of work.
  5. For each quote it resolves the two domain.Currency values from the list already in memory and calls Service.Record, which validates and issues an idempotent insert.
  6. Finish() commits once. Any error mid-loop triggers Restore() and aborts.
  7. Back at the boundary, the scheduler logs either “scheduled job completed” (with counts and duration) or “scheduled job failed” (with the error).

07 Data & idempotency design

Anchoring recorded_at to the rate's business date

Today Service.Create stamps RecordedAt = time.Now().UTC(). The table is an append-only log whose primary key is (from_currency_code, to_currency_code, recorded_at), and its own comment describes a row as “…was worth rate … as of recorded_at”. For a scheduled feed, the observation date is the meaningful instant, not the fetch time. 

-- store the API's business date at midnight UTC
recorded_at = time.Date(date.Year(), date.Month(), date.Day(), 0, 0, 0, 0, time.UTC)

Why this is better

  • Idempotent: two runs on the same business day collide on the primary key.
  • Correct history: the row reads “rate as of 2026-10-15”, not “fetched at 16:02”.
  • Safe restarts / catch-up: re-running can never duplicate or drift.
  • Lookup semantics preserved: GetByCurrencies(asOf) still takes the latest row ≤ asOf.

No migration needed

The existing primary key currency_exchange_rates_pk is exactly the conflict target ON CONFLICT (from_currency_code, to_currency_code, recorded_at) DO NOTHING needs. The rate stays numeric(18,4), the distinct-currencies and positive-rate checks are unchanged, and the HTTP “create rate by hand” endpoint keeps using time.Now() because it is a separate code path.

Idempotent insert

INSERT INTO currency_exchange_rates (from_currency_code, to_currency_code, rate, recorded_at)
VALUES ($1, $2, $3, $4)
ON CONFLICT (from_currency_code, to_currency_code, recorded_at) DO NOTHING;

Report whether a row was written from the command tag (RowsAffected() > 0) so SyncResult can distinguish recorded from already-present.

Precision

ExchangeRate is fixed-point 1e-4 (numeric(18,4)). Frankfurter returns up to five significant decimals (e.g. 0.94082), which domain.ParseExchangeRate rounds to four — fine for the currencies this app holds. Because we store the foreign→PLN direction, rates for very weak currencies (e.g. IRR, VES) could round toward zero and trip the “rate must be positive” check. Flagged as a risk; the seeded set (EUR, USD, PLN) is unaffected.

Never decode the rate as float64. Use json.Number for the rate field and pass its text to domain.ParseExchangeRate. This preserves the repo-wide “no floats for money/rates” rule and keeps the exact decimal the API returned.

9.2 Modify internal/service/currency_exchange_rate/currency_exchange_rate.go

Declare the outbound port and add the date-anchored, idempotent write path.

// Quote is one rate observation from an external provider:
// 1 unit of From was worth Rate units of To as of Date.
type Quote struct {
    From string
    To   string
    Rate domain.ExchangeRate
    Date time.Time
}

// RateSource is the outbound port for fetching current rates.
// Implemented in internal/adapter/frankfurter.
type RateSource interface {
    Latest(ctx domain.AppContext, base string, currencies []string) ([]Quote, error)
}

type Repository interface {
    Create(ctx domain.AppContext, exchangeRate domain.CurrencyExchangeRate, uow ...unit_of_work.UnitOfWork) error
    // CreateIfAbsent writes nothing if the pair+instant already exists.
    CreateIfAbsent(ctx domain.AppContext, exchangeRate domain.CurrencyExchangeRate, uow ...unit_of_work.UnitOfWork) (bool, error)
    GetByCurrencies(ctx domain.AppContext, from, to domain.Currency, asOf time.Time, uow ...unit_of_work.UnitOfWork) (*domain.CurrencyExchangeRate, error)
    List(ctx domain.AppContext, uow ...unit_of_work.UnitOfWork) ([]domain.CurrencyExchangeRate, error)
}

// Record stores an observed rate as of recordedAt, ignoring a record that
// already exists for the same pair and instant. Reports whether a row was written.
func (s *Service) Record(ctx domain.AppContext, from, to domain.Currency, rate domain.ExchangeRate, recordedAt time.Time, uow ...unit_of_work.UnitOfWork) (bool, error) {
    exchangeRate := domain.CurrencyExchangeRate{
        FromCurrency: from, ToCurrency: to, Rate: rate, RecordedAt: recordedAt.UTC(),
    }
    if err := exchangeRate.Validate(); err != nil {
        return false, err
    }
    return s.repository.CreateIfAbsent(ctx, exchangeRate, uow...)
}

Create is left untouched so the manual HTTP endpoint keeps its “now” timestamp.

9.3 Modify internal/adapter/gateway/postgres_currency_exchange_rate_repository.go

func (r *PostgresCurrencyExchangeRateRepository) CreateIfAbsent(ctx domain.AppContext, exchangeRate domain.CurrencyExchangeRate, uow ...unit_of_work.UnitOfWork) (bool, error) {
    db, err := dbFromUnitOfWork(r.db, uow...)
    if err != nil { return false, err }
    rateNumeric, err := exchangeRateToNumeric(exchangeRate.Rate)
    if err != nil { return false, err }
    sql, args, err := psql.Insert("currency_exchange_rates").
        Columns("from_currency_code", "to_currency_code", "rate", "recorded_at").
        Values(exchangeRate.FromCurrency.Code, exchangeRate.ToCurrency.Code, rateNumeric, exchangeRate.RecordedAt).
        Suffix("ON CONFLICT (from_currency_code, to_currency_code, recorded_at) DO NOTHING").
        ToSql()
    if err != nil { return false, err }
    tag, err := db.Exec(ctx.Context(), sql, args...)
    if err != nil { return false, err }
    return tag.RowsAffected() > 0, nil
}

9.4 New internal/adapter/frankfurter/frankfurter.go

// Package frankfurter implements currency_exchange_rate.RateSource using the
// Frankfurter API. It is the only place that speaks HTTP to an external provider.
package frankfurter

type Config struct {
    BaseURL        string `env:"FRANKFURTER_BASE_URL" bind:"optional" default:"https://api.frankfurter.dev"`
    TimeoutSeconds int64  `env:"FRANKFURTER_TIMEOUT_SECONDS" bind:"optional" default:"15"`
}

func LoadConfig() (Config, error) { return configuration.Load[Config]() }

type Client struct {
    baseURL string
    http    *http.Client
}

func NewClient(cfg Config) *Client {
    return &Client{
        baseURL: strings.TrimRight(cfg.BaseURL, "/"),
        http:    &http.Client{Timeout: time.Duration(cfg.TimeoutSeconds) * time.Second},
    }
}

type rateResponse struct {
    Date  string      `json:"date"`
    Base  string      `json:"base"`
    Quote string      `json:"quote"`
    Rate  json.Number `json:"rate"` // never float64
}

func (c *Client) Latest(ctx domain.AppContext, base string, currencies []string) ([]currency_exchange_rate.Quote, error) {
    out := make([]currency_exchange_rate.Quote, 0, len(currencies))
    for _, code := range currencies {
        if code == base { continue }
        q, found, err := c.rate(ctx, code, base)
        if err != nil { return nil, err }
        if found { out = append(out, q) }
    }
    return out, nil
}

func (c *Client) rate(ctx domain.AppContext, from, to string) (currency_exchange_rate.Quote, bool, error) {
    url := fmt.Sprintf("%s/v2/rate/%s/%s", c.baseURL, url.PathEscape(from), url.PathEscape(to))
    req, err := http.NewRequestWithContext(ctx.Context(), http.MethodGet, url, nil)
    // ... Do, then:
    //   404 / 422  → return Quote{}, false, nil   (provider doesn't know the pair)
    //   !200       → wrapped error               (aborts the whole run)
    //   decode rateResponse, then:
    rate, err := domain.ParseExchangeRate(body.Rate.String())
    if err != nil { return currency_exchange_rate.Quote{}, false, err }
    date, err := time.Parse("2006-01-02", body.Date)
    if err != nil { return currency_exchange_rate.Quote{}, false, err }
    return currency_exchange_rate.Quote{From: from, To: to, Rate: rate, Date: date}, true, nil
}

9.5 Modify internal/service/workflow/currency_exchange_rate_workflow.go

type CurrencyExchangeRateWorkflow struct {
    currencyService     *currency.Service
    exchangeRateService *currency_exchange_rate.Service
    rateSource          currency_exchange_rate.RateSource // new: the port, not the adapter
    uowManager          unit_of_work.Manager
}

type SyncResult struct {
    BaseCurrency string
    Fetched      int
    Recorded     int
    Skipped      int
}

func (w *CurrencyExchangeRateWorkflow) SyncDaily(ctx domain.AppContext) (SyncResult, error) {
    currencies, err := w.currencyService.List(ctx)
    if err != nil { return SyncResult{}, err }

    base, ok := findBase(currencies)
    if !ok { return SyncResult{}, fmt.Errorf("no base currency configured") }

    codes := make([]string, 0, len(currencies))
    for _, c := range currencies {
        if c.Code != base.Code { codes = append(codes, c.Code) }
    }
    result := SyncResult{BaseCurrency: base.Code}
    if len(codes) == 0 { return result, nil }

    quotes, err := w.rateSource.Latest(ctx, base.Code, codes) // network first…
    if err != nil { return SyncResult{}, err }
    result.Fetched = len(quotes)

    byCode := indexByCode(currencies)
    active, err := w.uowManager.Create(ctx) // …then the transaction
    if err != nil { return SyncResult{}, err }
    for _, q := range quotes {
        from, okF := byCode[q.From]
        to, okT := byCode[q.To]
        if !okF || !okT { continue }
        written, err := w.exchangeRateService.Record(ctx, from, to, q.Rate, q.Date, active)
        if err != nil { _ = active.Restore(ctx); return SyncResult{}, err }
        if written { result.Recorded++ } else { result.Skipped++ }
    }
    if err := active.Finish(ctx); err != nil { return SyncResult{}, err }
    return result, nil
}

9.6 New internal/infrastructure/scheduler/scheduler.go

// Package scheduler runs jobs on a cron schedule. It is the only package that
// imports the cron library; everything else sees just the Job callback.
package scheduler

var log = logger.New().WithComponent("scheduler")

type Job func(ctx domain.AppContext) error

type Config struct {
    Enabled        bool   `env:"EXCHANGE_RATE_SYNC_ENABLED" bind:"optional" default:"false"`
    Spec           string `env:"EXCHANGE_RATE_SYNC_CRON" bind:"optional" default:"0 16 * * *"`
    Timezone       string `env:"EXCHANGE_RATE_SYNC_TZ" bind:"optional" default:"UTC"`
    TimeoutSeconds int64  `env:"EXCHANGE_RATE_SYNC_TIMEOUT_SECONDS" bind:"optional" default:"60"`
    RunOnStart     bool   `env:"EXCHANGE_RATE_SYNC_RUN_ON_START" bind:"optional" default:"false"`
}

func LoadConfig() (Config, error) { return configuration.Load[Config]() }

type Scheduler struct {
    cron    *cron.Cron
    job     Job
    timeout time.Duration
}

func New(cfg Config, job Job) (*Scheduler, error) {
    loc, err := time.LoadLocation(cfg.Timezone)
    if err != nil { return nil, fmt.Errorf("scheduler: invalid timezone %q: %w", cfg.Timezone, err) }
    s := &Scheduler{job: job, timeout: time.Duration(cfg.TimeoutSeconds) * time.Second}
    s.cron = cron.New(
        cron.WithLocation(loc),
        cron.WithLogger(cronLogger{}),
        cron.WithChain(cron.Recover(cronLogger{}), cron.SkipIfStillRunning(cronLogger{})),
    )
    if _, err := s.cron.AddFunc(cfg.Spec, s.run); err != nil {
        return nil, fmt.Errorf("scheduler: invalid spec %q: %w", cfg.Spec, err)
    }
    return s, nil
}

func (s *Scheduler) Start() { s.cron.Start() }

// Stop waits for any in-flight run, bounded by ctx (main.go's shutdown budget).
func (s *Scheduler) Stop(ctx context.Context) error {
    select {
    case <-s.cron.Stop().Done(): return nil
    case <-ctx.Done(): return ctx.Err()
    }
}

func (s *Scheduler) run() {
    ctx, cancel := context.WithTimeout(context.Background(), s.timeout)
    defer cancel()
    var appCtx domain.AppContext
    appCtx.SetContext(ctx)
    appCtx.SetRequestSource(domain.RequestSource{Type: domain.RequestSourceTypeScheduler})
    appCtx.SetFlowID(uuid.NewString())

    started := time.Now()
    if err := s.job(appCtx); err != nil {
        log.WithContext(appCtx).Error("scheduled job failed",
            slog.String("error", err.Error()), slog.Duration("duration", time.Since(started)))
        return
    }
    log.WithContext(appCtx).Info("scheduled job completed", slog.Duration("duration", time.Since(started)))
}

// cronLogger adapts the shared slog logger to cron's Logger interface.
type cronLogger struct{}
func (cronLogger) Info(msg string, kv ...any)           { log.Slog().Info(msg, kv...) }
func (cronLogger) Error(err error, msg string, kv ...any) { log.Slog().Error(msg, append(kv, slog.String("error", err.Error()))...) }

11 Operations & failure modes

Lifecycle & shutdown

  • Scheduler starts after migrations, alongside the HTTP listener.
  • On SIGTERM, sched.Stop(shutdownCtx) shares the existing 10s budget with srv.Shutdown, waiting for any in-flight run.
  • SkipIfStillRunning guarantees a slow run never overlaps the next tick.
  • Recover turns a panic into a logged error instead of a crashed process.

Observability

  • One structured log line per run at component scheduler, tagged with flow_id, source_type=scheduler.
  • Success log carries fetched/recorded/skipped and duration.
  • Failure logs error + duration; the run is skipped, retried at the next tick.

Failure modes

  • Provider down / 5xx / timeout: run aborts, transaction never opens, error logged; next tick retries.
  • Unknown currency: that pair is silently skipped; others still record.
  • No base currency: fails fast with a clear error (also closes a documented invariant gap).
  • Duplicate run: no-ops via the primary key.

Multiple replicas

  • With one server instance, nothing more is needed.
  • If scaled out, each replica would run the job — but the insert is idempotent, so the outcome is still one row per pair/day (wasted HTTP, no corruption).
  • If strict single-runner semantics are later required, swap in a leader-electing scheduler (gocron's elector) — the scheduler package is the only file to change.

12 Risks & open questions

ItemImpactMitigation / decision needed
Fixed-point precision for extreme currencies ExchangeRate is 1e-4; foreign→PLN rates below ~0.00005 round to zero and fail validation. Immune for PLN/EUR/USD. Decide whether to (a) widen the rate scale, (b) store inversely for such currencies, or (c) accept and skip. Recommend deferring until such a currency is actually added.
Catch-up for missed days A server that was offline skips that day's rate. Idempotent design makes EXCHANGE_RATE_SYNC_RUN_ON_START safe. True historical backfill (Frankfurter's ?date=) is a future extension to the port.
Which currencies to sync Provider may not support a code the app holds. Drive it from the currencies table (not a hardcoded list); treat 404/422 as “skip this pair”.
Default enabled/disabled A background feature that suddenly makes outbound calls. Default EXCHANGE_RATE_SYNC_ENABLED=false; turn on per environment.
Library maintenance cadence robfig/cron's last release predates this project. Confined to one file; documented fallback to netresearch/go-cron if policy demands it.
Workflow constructor signature change Touches buildDeps and BuildTestDeps. Small, mechanical; called out in the checklist.
